# سياسة الخصوصية لتطبيق هدى وشفاء

## 1. مقدمة
تطبيق "هدى وشفاء" يحترم خصوصية مستخدميه. نلتزم بحماية أي معلومات شخصية تُجمع أثناء استخدام التطبيق.

## 2. المعلومات التي نقوم بجمعها
لا يقوم التطبيق بجمع أي بيانات شخصية مباشرة مثل الاسم أو البريد الإلكتروني، إلا إذا تم إدخالها طواعية (مثال: من خلال نموذج "اتصل بنا").
بيانات الاستخدام العامة (مثل معلومات الجهاز، نظام التشغيل) قد تُجمع لأغراض تحسين التطبيق.

## 3. الإعلانات
التطبيق قد يعرض إعلانات من خلال Google AdMob. هذه الإعلانات قد تستخدم ملفات تعريف الارتباط (Cookies) لتقديم محتوى مناسب، لكننا لا نشارك أي بيانات شخصية مع المعلنين.

## 4. الأطفال
التطبيق لا يستهدف الأطفال دون 13 سنة. إذا كنت ولي أمر وترغب في إزالة أي محتوى مرتبط بأطفالك، يرجى التواصل معنا عبر صفحة "اتصل بنا".

## 5. روابط الطرف الثالث
التطبيق قد يحتوي على روابط لتطبيقات أو مواقع أخرى. لسنا مسؤولين عن سياسات الخصوصية الخاصة بهذه المواقع أو التطبيقات.
